# Product Studio

> **Ideas are cheap. Evidence earns attention.**
> **Evidence unlocks the vote. Voting unlocks the next phase.**
> **Approved work creates contribution. GitHub preserves the history.**
> **Only one product receives the team's active focus at a time.**

This repository is the governance headquarters for Product Studio — a group of friends turning ideas into real, launched products through a transparent, fair, locked-phase process.

WhatsApp / Discord are for conversation. **GitHub is the source of truth** for ideas, decisions, work, votes, and contributions.

## How it works

```
IDEA BOARD 🔒 → Gate Vote → RESEARCH 🔒 → Gate Vote → VALIDATION 🔒 → Gate Vote →
SPECIFICATION 🔒 → Gate Vote → MVP DEVELOPMENT 🔒 → Gate Vote → TESTING / QA 🔒 →
Gate Vote → LAUNCH 🔒 → Gate Vote → GROWTH / SCALE
```

At every gate: **ADVANCE / REWORK / PAUSE / KILL**. No phase may be skipped. Every next phase starts locked. Required evidence must be complete before a gate vote can open.
