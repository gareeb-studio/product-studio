# Day 1 — Start Checklist (in order)

Do NOT start by building dashboard software. Run the process manually first; automate later (§17 of the source doc).

- [ ] 1. Create the GitHub **Organization** (group-owned/administered appropriately)
- [ ] 2. Create the **`product-studio`** repository inside it from this pack
- [ ] 3. Add every member with their **own** GitHub account
- [ ] 4. Create the labels in `docs/labels.md`
- [ ] 5. Protect `main` (no direct pushes once development begins)
- [ ] 6. Create Issue **SETUP-001** from `docs/first-issue-setup-001.md`
- [ ] 7. Everyone reviews governance; resolve disagreements on voting, contributions, ownership, spending **before** any product development
- [ ] 8. SETUP-001 vote passes → only then open the Idea Board
- [ ] 9. Set an idea submission window (e.g. opens Monday, closes Sunday)
- [ ] 10. Review ideas, hold Gate 0, research survivors, select **ONE** active product
- [ ] 11. Start contribution tracking from the first research task onward
