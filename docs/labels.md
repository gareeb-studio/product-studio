# GitHub Labels to create

| Label | Purpose |
|---|---|
| `idea` | Idea Board submission |
| `research` | Research phase / task |
| `voting` | An active or recorded vote |
| `validation` | Validation phase |
| `approved` | Approved / passed |
| `rework` | Sent back for rework |
| `paused` | Paused by vote |
| `killed` | Killed by vote |
| `building` | MVP development |
| `testing` | Testing / QA |
| `launched` | Launched |
| `growth` | Growth / Scale |

Create them in Settings → Labels, or with GitHub CLI after the repo exists:
`gh label create idea --repo <org>/product-studio` (repeat per label).
