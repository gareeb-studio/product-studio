# SETUP-001 — Approve Product Studio Governance

**Title:** `SETUP-001 — Approve Product Studio Governance`
**Labels:** `voting`, `approved` (after pass)

## Goal
All founding members review and approve the initial operating rules.

## Required before completion
- [ ] Voting threshold agreed (recommended: 2/3 normal gates, 75% major decisions)
- [ ] Gate system agreed
- [ ] Contribution system agreed
- [ ] Financial tracking agreed
- [ ] Product ownership principle agreed
- [ ] Member roles agreed
- [ ] Founding member list recorded (names + GitHub usernames)
- [ ] All founding members approve

## Until SETUP-001 passes
🔒 **IDEA SUBMISSION IS NOT YET OPEN**

*The first thing the team votes on should not be a product idea. The first vote should be the rules by which every future product will be selected and built.*
